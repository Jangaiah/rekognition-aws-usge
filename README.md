# rekognition-aws-usge
Frontend Angular application is inside folder UI
Backend Node Express app is inside server

Step 1: Go to respective folder do install dependencies

npm install


Step 2: For backend appliation create .env file with AWS credentials added as below, provide values without quotation marks.
.env file in server folder
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=
AWS_REGION=us-east-1

Step 3: Run both application with below command at respective folder inside

npm start

Step 4: Access application with http://localhost:4200 in browser modify ports if changed while running.
